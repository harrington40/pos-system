# TradeShield v1.0.0 - Quick Reference Card

## 🚀 QUICK START

### Build & Test (5 minutes)
```bash
cd extension
npm install
npm run build
# Then go to chrome://extensions/ → Load unpacked → extension/dist/
```

### Chrome Web Store Submit (1 hour)
1. Follow [CHROME_STORE_QUICK_START.md](CHROME_STORE_QUICK_START.md)
2. Create developer account ($5)
3. Upload `TradeShield-1.0.0.zip`
4. Add 5 screenshots (1280x800px)
5. Submit for review
6. **Live in 1-3 hours!**
