How the confidence level is computed

The model is intentionally simple and fully auditable.

Per-suite score (0–100):

pass_rate = passed / (total − skipped)

execution = (total − skipped) / total

score = 100·(0.60·pass_rate + 0.20·execution + 0.20·coverage)

score = 100·(0.75·pass_rate + 0.25·execution) when no coverage

Overall reliability (0–100):

test_score = Σ(score·weight·√size) / Σ(weight·√size)

reliability = 0.75·test_score + 0.25·coverage_score

Kind weights reflect how deterministic each layer is: unit 1.00 · component 0.90 · contract 0.80 · e2e 0.70 · ui 0.60. Heavier suites (√size) and more deterministic layers move the index more. Skipped tests count as not executed, so a suite that mostly skips cannot claim high confidence. A suite with any failing case is capped at Moderate.
